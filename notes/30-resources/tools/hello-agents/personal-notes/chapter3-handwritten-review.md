# 第三章手写复习笔记

> 类型：Personal Note  
> 主题：语言模型、词嵌入、RNN / LSTM、Transformer 与注意力

## 智能体四要素

智能体可以拆成四个基本要素：

- **感知器**：接收环境中的信息。
- **环境**：智能体所处并需要改变的外部世界。
- **执行器**：把决策转化为动作。
- **行动**：执行器对环境施加的具体操作。

## 统计语言模型

统计方法把语言模型看作“一个句子中每个词出现的条件概率的连乘”。给定前面的词，模型估计下一个词出现的概率。

N-gram 的主要问题：

1. **数据稀疏**：训练语料中没有出现过的词或词组，概率可能被估计为 0。
2. **泛化能力差**：模型只记住词频和相邻组合，难以理解不同词之间的语义相似性。

## 神经网络语言模型与词嵌入

神经网络语言模型的基本思路是：

1. 建立一个高维、连续的向量空间，把每个词映射到这个空间中的一个点，这个点就是词嵌入。
2. 学习“上下文 → 下一个词”的映射：输入前 `n-1` 个词，输出词表中下一个词的概率分布。

神经网络通过训练不断调整词向量，使语义或用法相近的词在向量空间中更接近。词向量也能表达部分类比关系，例如：

```text
king - man + woman ≈ queen
```

## 余弦相似度

两个向量的余弦相似度为：

```text
similarity(a, b) = cos(theta) = (a · b) / (|a| |b|)
```

- `0°`：相似度为 `1`，方向完全相同。
- `90°`：相似度为 `0`，方向正交，相关性弱。
- `180°`：相似度为 `-1`，方向完全相反。

这里比较的是向量方向，而不是 Token ID 的数字大小。对应代码见 [词向量与余弦相似度](../concepts/word-embeddings.md) 和 [`chapter3/demo2.py`](../../../../../chapter3/demo2.py)。

## RNN 与 LSTM

循环神经网络（RNN）按时间步依次处理输入，每一步接收当前输入 `x_t` 和上一步隐藏状态 `h_{t-1}`，再产生新的隐藏状态 `h_t`。这样可以把前面时间步的信息传到后面，形成“记忆”。

长短期记忆网络（LSTM）在 RNN 基础上增加门控结构，用输入门、遗忘门和输出门控制信息的写入、保留和输出，从而缓解普通 RNN 在长序列中的梯度消失与长期依赖问题。

## Transformer 与位置编码

Transformer 用注意力机制替代 RNN 的逐步递归计算，可以并行处理序列中的 Token。为了让模型知道 Token 的顺序，需要加入位置编码；本仓库的 [`chapter3/demo3.py`](../../../../../chapter3/demo3.py) 使用正弦和余弦函数构造位置编码。

## Q、K、V 与注意力

每个 Token 会通过线性变换得到三种向量：

- **Q（Query，查询）**：当前 Token 想查询什么信息。
- **K（Key，键）**：每个 Token 提供哪些可匹配的特征。
- **V（Value，值）**：每个 Token 实际提供的内容。

当前 Token 的 `Q` 与其他 Token 的 `K` 做点积，得到相关性分数；经过缩放和 `softmax` 后变成注意力权重，再用这些权重加权汇总 `V`：

```text
Attention(Q, K, V) = softmax(QK^T / sqrt(d_k))V
```

注意力权重越高，表示当前 Token 从对应 Token 获取的信息越多。多头注意力会在不同子空间并行学习不同类型的关系，例如指代、语法和语义关系。

## 复习串联

```text
N-gram：用词频统计下一个词
  -> 词嵌入：用向量表示词的语义
  -> RNN/LSTM：按时间步传递历史信息
  -> Transformer：用注意力并行建立上下文关系
  -> LLM：逐 Token 预测并生成文本
```

这条链路说明：大语言模型并不是跳过基础方法，而是在表示能力、上下文范围和计算方式上不断演进。
