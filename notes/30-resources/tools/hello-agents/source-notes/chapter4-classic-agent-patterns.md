## 学习目标

这一章先把“模型会回答”推进到“Agent 会按范式做事”。重点不是再讲一个更大的模型，而是理解：Agent 如何把思考、行动、观察、规划和反思组织成可运行的流程。

```text
目标 -> 推理 -> 工具行动 -> 环境反馈 -> 调整策略 -> 完成任务
```

## ReAct：边想边做

ReAct 的核心是把 Reasoning 和 Acting 放进同一个循环中。模型先说出当前判断，再选择工具行动，随后根据 Observation 继续下一步。它和第一章的 [[Agent Loop]] 很像，但更强调“思考轨迹”和“工具行动”的交替。

后续补充时可以写：

- 我理解中的 Thought / Action / Observation 分别是什么。
- 它为什么比单纯 Prompt 问答更适合搜索、查询、计算类任务。
- 工具失败、信息不足、循环过长时应该如何停止。

## Plan-and-Solve：先规划再求解

Plan-and-Solve 强调先把复杂任务拆成计划，再按步骤执行。它适合那些“一步想不完”的问题，例如多条件查询、复杂写作、数据分析或代码修改。

后续补充时可以写：

- Plan 阶段应该写到什么粒度。
- Solve 阶段如何检查每一步是否完成。
- 计划错误时，是重新规划还是局部修正。

## Reflection：执行后的自我修正

Reflection 让 Agent 在一次回答或行动后检查结果，发现错误、遗漏或不符合目标的地方，再进入下一轮修正。它不是“模型自信地再说一遍”，而是把评估标准、反馈来源和修改动作明确化。

后续补充时可以写：

- 反思到底反思什么：事实、格式、步骤、工具结果，还是目标偏差。
- 什么时候反思有用，什么时候只是增加成本。
- 如何避免 Agent 陷入无限自我修改。
