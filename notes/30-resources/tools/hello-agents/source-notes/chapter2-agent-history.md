> 类型：Source Note

## 核心摘要

智能体史是一条“问题驱动”的演化链：符号规则解决可解释推理，专家系统沉淀领域知识，连接主义从数据中学习表示，强化学习优化序贯决策，LLM Agent 则把语言理解、规划和工具使用组合起来。

每种范式都有代价：符号系统遇到知识获取瓶颈和常识问题；神经网络难解释且依赖数据；强化学习受奖励设计、探索安全和样本效率约束；LLM 仍会幻觉、受上下文和成本限制。

## 从符号到学习

- **符号主义**：知识以实体、规则和逻辑操作表示，专家系统通过知识库与推理机工作。
- **专家系统**：正向链是数据驱动，反向链是目标驱动；置信因子用于表达不确定结论。
- **连接主义**：知识分布在网络参数和向量表示中，擅长模式识别与泛化。
- **强化学习**：Agent 通过状态、动作、奖励与环境互动，学习最大化长期回报的策略。
- **LLM Agent**：神经模型负责生成与规划，结构化消息、工具和程序约束提供可执行边界。

## 代码锚点

[`chapter2/demo.py`](../../../../../code/chapter2-demo.md) 是规则驱动的 ELIZA 风格程序。正则模式是显式知识，响应模板是规则结论，匹配循环是简化推理机。它可解释、稳定，但没有长期状态、环境模型或自主学习，适合用来对照现代 Agent 的新增能力。
